# 📦 بوت متابعة أسعار المنتجات — Telegram Price Tracker Bot

بوت Telegram عربي لمتابعة أسعار المنتجات على **Amazon.eg** و **Noon Egypt**،
يدعم ثلاثة أنواع من التنبيهات: **نطاق سعري**، **سعر أقصى**، و**نسبة انخفاض**،
مع سجل أسعار تاريخي ورسوم بيانية ولوحة أدمن كاملة.

---

## ✨ أهم المميزات

| الميزة | الوصف |
|---|---|
| 📊 نطاق سعري | حدد أدنى وأعلى سعر — الإشعار عند وصول السعر للحد الأعلى أو **أي سعر أقل منه** (حتى تحت الحد الأدنى!) |
| 🔝 سعر أقصى | إشعار عندما يصبح السعر ≤ السعر الذي حددته |
| 📉 نسبة انخفاض | إشعار عند انخفاض السعر عن سعر مرجعي بنسبة تحددها (مع توضيح طريقة الحساب) |
| 🔔 منع التكرار | إشعار واحد عند أول تحقق للشرط، وإعادة تسليح تلقائية عند ارتفاع السعر |
| ➕ تنبيه التحسن | إشعار إضافي اختياري عند انخفاض السعر أكثر بنسبة تحددها |
| ✏️ تعديل بدون حذف | عدّل نوع التنبيه وقيمه من قائمة «منتجاتي» في أي وقت |
| 📈 سجل الأسعار | تاريخ حقيقي فقط + إحصائيات (أقل/أعلى/متوسط/التغير) بفترات متاحة فعلًا |
| 📉 رسوم بيانية | آخر 7 أيام / 30 يومًا / كل التاريخ، مع تظليل النطاق المستهدف |
| 🛡️ لوحة أدمن | إحصائيات، إدارة مستخدمين، إعدادات، متاجر، نسخ احتياطي، إشعارات |

## 🧮 منطق التنبيه — بالتفصيل

### النطاق السعري (مثال: 3500 - 4000)

| السعر الحالي | الإجراء |
|---|---|
| 5000 / 4500 / 4100 | ❌ لا إشعار (أعلى من الحد الأعلى) |
| 4000 | ✅ إشعار |
| 3900 / 3500 / 3000 / 2500 | ✅ إشعار (الحد الأعلى فقط هو الذي يتحكم) |
| 4001 | ❌ لا إشعار |

**قواعد الحالة:**
- أول تحقق للشرط → إشعار → يصبح التنبيه غير مسلح.
- ما دام الشرط متحققًا → لا تكرار.
- ارتفع السعر فوق الحد → إعادة تسليح تلقائيًا.
- انخفض مجددًا → إشعار جديد.

### نسبة الانخفاض (مثال: مرجعي 5000 ونسبة 10%)
السعر المستهدف = 5000 × (1 − 10%) = **4500** → إشعار عند 4500 أو أقل.
يمكن اختيار السعر المرجعي من: السعر وقت الإضافة، أو السعر الحالي وقت التعديل، أو إدخاله يدويًا.

## 🚀 خطوات التشغيل على Windows (خطوة بخطوة)

### 1. تثبيت Python
حمّل Python 3.11 أو أحدث من [python.org](https://www.python.org/downloads/)
وفعّل خيار **Add Python to PATH** أثناء التثبيت.

### 2. إنشاء البوت من BotFather
1. افتح Telegram وابحث عن **@BotFather**.
2. أرسل `/newbot` واتبع الخطوات.
3. انسخ **التوكن** الذي سيعطيك إياه (شكله مثل `123456:AA...`).

### 3. الحصول على Telegram ID الخاص بك (الأدمن)
1. ابحث عن **@userinfobot** وأرسل له أي رسالة.
2. سيعطيك رقم ID — انسخه.

### 4. التثبيت
```bat
:: داخل مجلد المشروع
install.bat
```
هذا ينشئ بيئة افتراضية ويثبت كل المكتبات وينشئ ملف `.env`.

### 5. إعداد ملف .env
افتح ملف `.env` وعدّل:
```env
BOT_TOKEN=التوكن_الذي_من_BotFather
ADMIN_IDS=رقم_ID_الخاص_بك
```

### 6. التشغيل
```bat
run.bat
```
عند ظهور "Bot is polling" البوت يعمل ✅

### 7. اختبار إضافة أول منتج
1. افتح بوتك في Telegram واضغط **Start**.
2. اضغط **➕ إضافة منتج جديد** وأرسل رابط منتج من Amazon.eg أو Noon Egypt.
3. اختر نوع التنبيه وأدخل القيم واضغط **✅ تأكيد بدء المتابعة**.

### 8. النسخ الاحتياطي
```bat
backup.bat
```

### 9. التشغيل على استضافة دائمة
- يكفي خادم Windows صغير أو VPS: ضع المجلد وشغّل `run.bat` (أو استخدم `nssm` لتشغيله كخدمة).
- على Linux: `python3 -m venv venv && venv/bin/pip install -r requirements.txt && venv/bin/python main.py` مع systemd.
- أو انشره مجانًا على **Render** — انظر القسم التالي.

## ☁️ النشر على Render (مجانًا)

البوت يدعم وضع **Webhook** تلقائيًا داخل Render — لا تعديل كود مطلوب.

### الخطوات
1. ارفع المشروع إلى مستودع **GitHub** (لا ترفع `.env` أبدًا — موجود في `.gitignore`).
2. من [render.com](https://render.com): **New → Blueprint** واختر المستودع — سيقرأ `render.yaml` تلقائيًا.
3. من صفحة الخدمة → **Environment** أضف متغيرين سِرّيين:
   - `BOT_TOKEN` = التوكن من BotFather
   - `ADMIN_IDS` = رقم الـ Telegram ID الخاص بك
4. اضغط **Apply** — بعد دقيقة يشتغل البوت ويصل الـ Webhook تلقائيًا.
5. **افتح البوت من داخل Telegram** على `t.me/اسم_بوتك` — ليس بالمتصفح (البوت ليس موقعًا؛ الرابط في Render مجرد عنوان تقني `/healthz` و`/webhook`).

### ⚠️ ملاحظتان مهمتان للخطة المجانية
| المشكلة | الحل |
|---|---|
| الخدمة "تنام" بعد 15 دقيقة بدون زيارات → الفحص المجدول يتوقف | سجل في [UptimeRobot](https://uptimerobot.com) (مجاني) ping كل 10 دقائق على `https://اسم-خدمتك.onrender.com/healthz` — يبقيها مستيقظة |
| القرص مؤقت: قاعدة البيانات **تتسحب** عند كل إعادة نشر/restart | قبل أي تغيير خذ نسخة من لوحة الأدمن (`/admin` → 💾 النسخ الاحتياطي وحمّل الملف)، أو استخدم خطة مدفوعة بقرص دائم، أو انقلها لـ VPS |

## ⚠️ ملاحظات مهمة عن مصادر الأسعار

- الموصلات تقرأ **صفحات المنتج العامة فقط** — لا تتجاوز CAPTCHA ولا أنظمة الحماية.
- إذا رجع المتجر صفحة حماية أو فشل نزع السعر، يُسجل الفشل في سجل الفحوصات
  ويُبلغ الأدمن بعد تكراره — **لا يعرض البوت أي سعر غير حقيقي أبدًا**.
- إن احتجت مصدرًا أكثر موثوقية مستقبلًا، أضف موصلًا جديدًا في `app/providers/`
  وسجّله في `registry.py` دون تغيير أي شيء آخر.

---

## 🛡️ ملاحظات الأمان

- التوكن ومعرفات الأدمن في `.env` فقط — لا أسرار داخل الكود.
- منع SSRF: الروابط تُقبل فقط لنطاقات المتاجر المدعومة.
- حماية لوحة الأدمن بالـ Telegram ID، وكل مستخدم لا يرى إلا متابعاته.
- منع تكرار الإشعارات عبر تحديث SQL شرطي ذري (يعمل حتى مع دورتي فحص متوازيتين).
- الإشعارات تُسجل بحالة `pending` قبل الإرسال — لا تضيع عند إعادة التشغيل.
